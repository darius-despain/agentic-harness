## Scope and limits

The examples support targeted changes to review decisions, re-review, linked behavior, validation reporting, and concise drafting. They do not justify hard-coding MIQA fee-classification rules, assuming every review needs multiple repositories, or forcing rejection. Re-review requests occur for two distinct PRs; duplicate statements about #268 are not counted as independent defect recurrence.

The existing immutable-target, secrets, scoped delegation, no-external-write, and access-checkpoint safeguards remain. Deferred: native agent registration, global installation, automatic scheduling, automatic review posting, and implementation in consumer repositories. None is required by this revision.

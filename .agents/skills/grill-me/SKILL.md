# Grill Me

Work toward an agreed definition of done through a focused conversation.

1. Read the ticket or proposal and its relevant project context. Check facts
   the project can answer. Ask the user for decisions and any context only they
   can provide.
2. Of the decisions the user can make now, start with the one that most affects
   scope, behavior, or verification. Ask one question at a time by default.
   Give a recommended answer and a short reason when the tradeoff is clear.
   Group independent questions if the user asks to work through them in batches.
3. Use each answer to choose the next question. Resolve prerequisites before
   asking questions that depend on them. Carry forward decisions the user has
   already made and stop asking once the outcome can be verified.
4. Summarize the agreed scope, observable acceptance criteria, and how to
   check them. Call out unresolved decisions and ask the user to confirm the
   summary. Keep this session focused on clarification until the user
   authorizes the next step.
